# Security

Asima Hub checks the signature of the news and downloads feed, every download, and what it writes
to a USB stick. A weakness in any of that matters: please report it privately, never in a public
issue.

On [github.com/asimaos/asimaos-hub](https://github.com/asimaos/asimaos-hub), open the **Security**
tab and choose **Report a vulnerability**. Only the maintainers see it. The rest of the policy (what
to tell us, when you hear back) is Asima OS's:
[SECURITY.md](https://github.com/asimaos/asimaos/blob/main/SECURITY.md).

Supported: the newest version.
